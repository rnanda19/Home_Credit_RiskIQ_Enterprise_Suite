**What these are**: the real output format this suite produces — an HTML
dashboard, a Word report, and an Excel workbook — generated by actually
running Notebook 01 end-to-end (real code, real models, real statistical
checks, real chart/report generation).

**What these are not**: real results. This file was generated against the
**synthetic verification fixture** used to check this repo before delivery
(same schema/dtypes as the real Home Credit tables, small row counts) —
never against the real, downloaded Kaggle dataset. That is why it is
prefixed `SAMPLE_`. This suite never ships output derived from anyone's
actual data in a public repo (see the zero-fabrication principle in the
[root README](../../README.md)); it exists purely so a reader can open a
real, fully-formatted deliverable — the SHAP chart, the model-screening
table, the decile-calibration chart — without cloning the repo and running
the notebook themselves.

**Run it on the real dataset yourself** to get the real version — see the
[`04_mega_project_4_delinquency_prevention` README](../README.md).

**How GitHub actually opens this file when you click it**: the `.html`
link below opens GitHub's raw-source view, not a rendered page — for a
live, rendered dashboard, use the
[Live Dashboards](../../README.md#live-dashboards) links in the root
README instead (GitHub Pages). The `.docx`/`.xlsx` links open a "can't
preview this file" page with a Download button — standard GitHub behavior
for any Office document in any repository — download and open in
Word/Excel to view them.
