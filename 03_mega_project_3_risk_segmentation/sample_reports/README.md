# Sample Reports — Mega Project 3

**What these are**: the real output format this suite produces — an HTML
dashboard, a Word report, and an Excel workbook per problem, plus a
consolidated executive rollup in the same three formats — generated by
actually running each notebook end-to-end (real code, real K-Means
clustering, real chi-square/Cramer's V statistical validation, real
cross-axis synthesis, real chart/report generation).

**What these are not**: real results. Every file here was generated
against the **synthetic verification fixture** used to check this repo
before delivery (same schema/dtypes as the real Home Credit tables, small
row counts) — never against the real, downloaded Kaggle dataset. That is
why every file is prefixed `SAMPLE_`. This suite never ships output derived
from anyone's actual data in a public repo (see the zero-fabrication
principle in the [root README](../../README.md)); these exist purely so a
reader can open a real, fully-formatted deliverable — the segment
aggregation tables, the cross-axis risk-differentiation ranking, the
SMART-format executive insights — without cloning the repo and running
notebooks themselves.

**Run it on the real dataset yourself** to get the real version of every
file below — see the [`03_mega_project_3_risk_segmentation` README](../README.md).

**How GitHub actually opens these files when you click them**: `.html`
links below open GitHub's raw-source view, not a rendered page — for a
live, rendered dashboard, use the
[Live Dashboards](../../README.md#live-dashboards) links in the root
README instead (GitHub Pages). `.docx`/`.xlsx` links open a "can't
preview this file" page with a Download button — standard GitHub
behavior for any Office document in any repository — download and open
in Word/Excel to view them.
